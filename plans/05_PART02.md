## P02-S07 — V2XPnP

**File:** `drivex/scenes/part02/p02_s07_v2xpnp.py`
**Class:** `P02S07V2XPnP`
**Background:** WHITE
**Duration:** ~120s (longest in Part 2)

### What
Three sub-acts answering the 3 questions:
- **What:** early / intermediate / late fusion choices, all with temporal dimension.
- **When:** one-step communication when cars are close; temporal attention compresses history.
- **How:** temporal attention (within agent) → spatial attention (across agents) → multi-agent spatio-temporal representation → detection + prediction.

### Source
[script_part2.md](../materials/scripts/script_part2.md) — slides 10–15.

### Reviews
- Review 1: "các chữ gần mũi tên quá, tại scene fusion (recommend là xóa box màu vàng n-frames gì đó), thì nó sẽ đỡ gần nhau hơn, về cái how to fuse thì cũng đẹp rồi nhưng chỗ box của spatial attention thì nó hơi gần temporal feature và agent2 feature... 2 mũi tên từ 2 box feature đang trỏ sai, và box detection không align theo hàng ngang với multi-agent spatio-temporal representation và nó quá gần nên bị overlap luôn"
- Review 2 (longer): "tôi nghĩ bạn nên move tổng thể pipeline lên trên... 2 mũi tên từ feature trỏ vào khối spatial attention vẫn lỗi... khối đó overlap với temporal feature luôn, overlap với khối màu vàng multiagent spatio-temporal. bạn cần align lại sao cho middle của khối spatial attention theo chiều ngang sẽ là trung tâm của 2 middle của 2 khối feature, các độ dài ngang ra xa một xíu để có space cho mũi tên, tiếp theo đó là hãy chía mũi tên xuống tới khối spatio-temporal tại vì nhét 1 hàng ngang là không có đủ chỗ, rồi 2 khối detection và prediction thì tôi nghĩ flow nên kiểu từ trái qua phải xong từ trên xuống dưới xong từ phải qua trái thì sẽ có nhiều space và nói được các bước"

### Critical fixes (Review #2 is detailed — implement exactly)
1. **Pipeline shifted UP** to give space for downstream blocks.
2. **Spatial attention block centered** between the two feature blocks (vertically aligned middles).
3. **Boxes spread further apart** for arrow space.
4. **Spatial attention output → multi-agent spatio-temporal block via DOWNWARD arrow**, not horizontal — there's not enough horizontal room.
5. **Detection and Prediction blocks**: flow goes left→right→down→left (S-curve / serpentine). Don't try to fit in one row.
6. **Remove the yellow "n-frames" box** that crowds neighbors (review #1).

### Layout (revised — serpentine)
```
[Agent1 history] ──→ [Temporal Attn 1] ──┐
                                          ├──→ [Spatial Attn]
[Agent2 history] ──→ [Temporal Attn 2] ──┘         │
                                                    ▼
                              [Multi-agent spatio-temporal repr.]
                                                    │
                            ┌───────────────────────┤
                            ▼                       ▼
                       [Detection]           [Prediction]
```

### Animation flow
1. Header "V2XPnP — what / when / how"
2. **What:** 3 fusion strategies (early/inter/late) — boxes appear with brief labels
3. **When:** vehicle distance illustration → "one-step comm" highlighted, with temporal-attention compression metaphor
4. **How:** the serpentine pipeline above
   - Agent 1 + Agent 2 history (left, vertical stack)
   - Each → Temporal Attn block (horizontal arrow)
   - Both Temporal Attn → Spatial Attn (converge horizontally; vertical center alignment)
   - Spatial Attn → Multi-agent rep (DOWN arrow)
   - Multi-agent rep → Detection (DOWN-LEFT) and → Prediction (DOWN-RIGHT)
5. Result label: "spatio-temporal fusion in one framework"
6. Brief mention of V2XPnP-Seq dataset (just one line — full dataset detail in S08)
7. End

### Pipeline rendering helper
Use a strict alignment helper:
```python
def _block(name, w=2.2, h=0.9, color=COL_BLUE):
    box = RoundedRectangle(corner_radius=0.1, width=w, height=h,
                           fill_color=COL_DEEP_BLUE, fill_opacity=1,
                           stroke_color=color, stroke_width=1.5)
    return VGroup(box, Text(name, font_size=18, color=COL_NAVY).move_to(box))

# After creating all blocks, align centers explicitly:
spatial_attn.align_to(VGroup(temporal1, temporal2), DOWN)  # or UP, as needed
spatial_attn.move_to([temporal1.get_x() + (temporal2.get_x()-temporal1.get_x())/2, spatial_attn.get_y(), 0])
```
