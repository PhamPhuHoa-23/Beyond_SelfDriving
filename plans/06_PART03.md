1. **Multiple aligned points** — show many points (~5 pairs), not just 2.
2. **Coordinate axes** drawn for each frame (each sensor has its own axes).

4. **Lift the 4 mini-coord-systems UP** so they don't overlap with the ground-truth-frame coord system + "without calibration" caption.

### Visual blueprint

### Visual blueprint

   Each agent:  [LiDAR] → [detect] → [bbox]
                              ↓                ↓
                       send bbox     send bbox

   ┌── Naive NMS ────────────────┐
   │ pick highest confidence     │
   │  ⚠ confidence ≠ physical    │
   │     fidelity                │
   │  bbox A: high conf, bad ori │   ← bbox A rotates wrong way
   │  bbox B: low conf, good ori │   ← bbox B has correct orientation
